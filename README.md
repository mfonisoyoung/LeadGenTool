# LeadGenTool
A tool that helps automatically find people and send them custom emails using a spreadsheet and automation.

## Project Description

This project is an automated system that helps businesses find potential customers and send them personalized emails without doing everything manually.

It works by using a Google Sheet to store lead information, then automatically processes each lead, creates a custom message for them, and sends the email through Gmail using Make.com automation.

The goal of this system is to save time, reduce manual outreach work, and make it easier to contact many people in a smart and organized way.
